Probleme bei der Aufnahme

iPhone stoppt die Aufnahme mitten im Klettern? Prüfen Sie zuerst den gespeicherten Clip

Finden Sie die Ursache einer abgebrochenen Kletteraufnahme, ohne Ihr Material zu löschen. Prüfen Sie das gespeicherte Ende, Temperaturwarnungen, den Speicherplatz und machen Sie einen kurzen Kameratest.

Veröffentlicht am 17. November 2026 · Vom CruxCut-Team

Beginnen Sie mit dem, was tatsächlich gespeichert wurde

Sie beenden einen Versuch, gehen zum Handy zurück und stellen fest, dass die Aufnahme vor dem Top geendet hat. Bevor Sie den Editor wechseln, öffnen Sie das Original in Fotos und spielen Sie die letzten Sekunden ab. Notieren Sie die gespeicherte Dauer, die Stelle, an der es endet, und jede Meldung, die das Handy angezeigt hat. Behalten Sie dieses Original, auch wenn es unvollständig ist.

Wenn das Original das Top enthält, eine bearbeitete Kopie aber nicht, ist das ein anderes Problem. Prüfen Sie die Schnittpunkte und vergleichen Sie den gespeicherten Export. Ein Editor kann keine Bewegung zurückholen, die die Kamera nie aufgenommen hat; ein kürzerer Export beweist nicht, dass die Kamera gestoppt hat.

1. Eine Temperaturwarnung ist ein Grund aufzuhören

Apple erklärt, dass längere Kameranutzung bei Hitze oder direkter Sonneneinstrahlung die Gerätetemperatur beeinflussen kann und dass Kamerafunktionen vorübergehend deaktiviert werden können, wenn das Gerät zu warm wird. Das ist eine mögliche Erklärung, die Sie prüfen sollten, aber kein Beweis dafür, dass Hitze eine bestimmte Aufnahme beendet hat.

Wenn das iPhone eine Temperaturwarnung anzeigt, folgen Sie den Hinweisen von Apple zur Temperatur: Schalten Sie es aus, bringen Sie es an einen kühleren Ort ohne direkte Sonne und lassen Sie es abkühlen. Starten Sie die Aufnahme nicht immer wieder neu, um eine Warnung zu umgehen. Ein warmes Handy ohne Warnung ist für sich genommen kein Hinweis auf Überhitzung; Apple beschreibt auch eine normale Erwärmung bei der Kameranutzung.

Wählen Sie bei einer Session draußen nach Möglichkeit eine schattige, erlaubte Filmposition. Legen Sie ein Handy nicht in einen Landebereich, auf einen Laufweg oder in den Arbeitsbereich der sichernden Person, um es aus der Sonne zu halten. Wenn es keinen sicheren Platz zum Filmen gibt, verzichten Sie auf die Aufnahme. Siehe die Checkliste für eine sichere Filmposition.

2. Lesen Sie Speicher- oder Kamerameldungen, bevor Sie Einstellungen ändern

Prüfen Sie den verfügbaren Gerätespeicher unter Einstellungen > Allgemein > iPhone-Speicher. Notieren Sie, was das Handy anzeigt, statt anzunehmen, dass ein kurzer Clip bedeutet, der Speicher war voll. Es gibt keinen allgemeingültigen Schwellenwert für freien Speicher, der für jede Auflösung, Bildrate, jedes Gerät und jede Aufnahmelänge gilt.

Wenn der Platz knapp ist, verschieben Sie über Ihren normalen Backup-Ablauf geprüfte Kopien von Dateien, die Sie auf dem Handy nicht mehr brauchen. Vergewissern Sie sich, dass sich eine Kopie öffnen lässt, bevor Sie etwas entfernen. Löschen Sie nicht die einzige Kopie einer Klettersession und gehen Sie nicht davon aus, dass ein Cloud-Vorschaubild bedeutet, dass das vollständige Original anderswo sicher verfügbar ist. Unsere Checkliste zu iCloud-Originalen erklärt dieses separate Problem.

3. Machen Sie vor dem nächsten Versuch einen kurzen, gespeicherten Test

Nachdem Sie eine Warnung behoben haben, verwenden Sie dieselbe Kamera-App, dasselbe Objektiv und denselben Videomodus, die Sie nutzen wollen. Nehmen Sie von einer sicheren Position aus einen kurzen Test auf, stoppen Sie ihn selbst und spielen Sie die gespeicherte Datei bis zum Ende ab. Vergewissern Sie sich, dass Bild und Ton vorhanden sind. Eine laufende Vorschau oder ein Timer ist nicht dasselbe wie eine geprüfte, gespeicherte Aufnahme.

Wenn dieser Test klappt, probieren Sie in einer normalen Pause einen etwas längeren Test. Behalten Sie das Handy im Blick und halten Sie es anderen aus dem Weg. Ein erfolgreicher kurzer Test garantiert nicht, dass eine ganze lange Session zuverlässig aufgenommen wird. Bitten Sie niemanden, einen anstrengenden Aufstieg nur zur Diagnose der Kamera zu wiederholen.

Wenn Sie eine niedrigere Auflösung oder Bildrate vergleichen möchten, ändern Sie nur eine Einstellung und vergleichen Sie gespeicherte Tests. Das kann helfen, eine Bedingung einzugrenzen; es ist keine garantierte Lösung, und diese Anleitung schreibt keinen bestimmten Modus vor. Notieren Sie die ursprünglichen Einstellungen, damit Sie Ihr bevorzugtes Setup wiederherstellen können.

4. Aufnahmefehler von App-spezifischen Problemen trennen

Wenn eine Kamera-App eines Drittanbieters wiederholt stoppt, die integrierte Kamera-App denselben kurzen Test aber aufnimmt, bewahren Sie beide Ergebnisse auf. Notieren Sie Kamera-App und Version, iOS-Version, Videomodus, Dauer, Speicheranzeige und die genaue Warnung oder Fehlermeldung. Dieser Vergleich ist für den Support nützlich, beweist aber keinen Softwarefehler und schließt Unterschiede zwischen Aufnahmemodi nicht aus.

Wenn auch die integrierte Kamera stoppt, nehmen Sie nicht wiederholt lange Versuche als Test auf. Folgen Sie den aktuellen Support-Hinweisen des Geräteherstellers. Setzen Sie das Handy nicht zurück, entfernen Sie keine Apps und verwerfen Sie kein Material, nur weil die Ursache unklar ist.

Führen Sie ein kleines Störungsprotokoll

  • Gespeicherte Dauer des Originals und der letzte sichtbare Zug.
  • Ob das Handy gestoppt hat, die App geschlossen wurde oder nur der Export kürzer war.
  • Genauer Warnungstext, falls vorhanden; schließen Sie nicht allein aus Wärme auf eine Warnung.
  • Kamera-App, Objektiv, Auflösung, Bildrate und ungefähre Bedingungen der Session.
  • Verfügbarer Speicher und Ergebnisse eines kurzen gespeicherten Tests.

Dieses kleine Protokoll ist nützlicher, als mehrere Einstellungen gleichzeitig zu ändern. Sobald ein vollständiges Original vorliegt, gehen Sie zur Beta-Analyse über oder erstellen Sie einen separaten Schnitt zum Teilen. Bewahren Sie das Original auf, bis die exportierte Kopie geprüft ist.

Geltungsbereich und Quelle

Geprüft am 17. November 2026. Die obigen Aussagen zur Temperatur beruhen auf Apples Hinweisen zur Temperatur von iPhone und iPad. Der Vergleichsablauf ist eine redaktionelle Empfehlung, keine gemessene Diagnose eines bestimmten Geräts. Für CruxCut wird weder eine Wiederherstellung abgebrochener Aufnahmen noch ein automatischer Kamera-Neustart noch eine Überhitzungsschutzfunktion behauptet. Bedienelemente und Warnungen unter Android unterscheiden sich; halten Sie sich an die Hinweise Ihres Geräteherstellers, statt iPhone-Menüs wörtlich zu übertragen.
