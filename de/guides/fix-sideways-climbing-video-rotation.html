Probleme mit der Videoausrichtung

Seitlich gedrehtes Klettervideo vor dem Bearbeiten korrigieren

Finden Sie heraus, warum ein Klettervideo seitlich gedreht geöffnet wird: Vergleichen Sie Player, korrigieren Sie die Ausrichtung einmal und prüfen Sie die gespeicherte Datei, bevor Sie zuschneiden oder teilen.

Veröffentlicht am 4. November 2026 · Vom CruxCut-Team

Erst die Ausrichtung korrigieren, dann den Bildausschnitt wählen

Ein Klettervideo kann in der Galerie Ihres Handys aufrecht aussehen, nach dem Import oder Teilen aber seitlich gedreht sein. Bevor Sie die halbe Wand wegschneiden, klären Sie, wie das gespeicherte Video angezeigt werden soll. Die Ausrichtung ist ein anderes Problem als ein Hochformat-Zuschnitt: Drehen stellt die Wand aufrecht; Zuschneiden bestimmt, welcher Teil dieses aufrechten Bildes sichtbar bleibt. Beginnen Sie mit der Originalaufnahme und lassen Sie sie unverändert.

Dasselbe Original an zwei Stellen vergleichen

Öffnen Sie das Original in der Galerie und dann in dem Editor oder Player, in dem das Problem aufgetreten ist. Achten Sie auf die tatsächliche Wand und die Personen, nicht auf die Position der Wiedergabesteuerung. Eine Decke, ein aufrechter Türrahmen oder eine stehende Person können helfen, aber eine überhängende Wand allein ist kein verlässlicher Bezug für die Senkrechte. Notieren Sie, ob das ganze Bild um eine Vierteldrehung gedreht ist, auf dem Kopf steht oder nur in einem anders geformten Rahmen angezeigt wird.

Wenn nur eine App die Datei seitlich gedreht anzeigt, spricht das für einen Unterschied bei Wiedergabe oder Import, beweist aber nicht, dass die Kamera beschädigte Bildpunkte aufgezeichnet hat. Videodateien können die Anzeigeausrichtung getrennt von den gespeicherten Bildabmessungen angeben, und Apps können diese Information unterschiedlich auslegen. Diese Anleitung benennt keinen bestimmten App-Fehler und verspricht nicht, dass jeder Editor jede Quelldatei gleich behandelt.

Drehung, Zuschnitt und Bildschirmverhalten auseinanderhalten

Fragen Sie zuerst, ob das Drehen des gesamten Bildes die Szene aufrecht stellen würde. Wenn ja, untersuchen Sie die Drehung. Wenn die Szene aufrecht ist, aber die Füße fehlen, untersuchen Sie stattdessen Zuschnitt und Bildausschnitt. Wenn das Bild aufrecht ist und daneben leerer Raum bleibt, ist es vielleicht einfach eine Querformat-Aufnahme, die auf einer Hochformat-Fläche angezeigt wird. Sie so zu strecken, dass sie die Fläche füllt, verändert die Körperproportionen und ist keine Korrektur der Ausrichtung.

Wenn Sie das Handy beim Ansehen drehen, kann sich die Oberfläche drehen, ohne dass sich die gespeicherte Datei ändert. Ebenso kehrt ein Spiegeln- oder Umkehren-Befehl das Bild um; er erfüllt nicht dieselbe Aufgabe wie eine Drehung um eine Vierteldrehung. Halten Sie links und rechts konsistent, wenn Sie den Clip zur Beta-Analyse nutzen möchten.

Eine kontrollierte Korrektur vornehmen

Wenn der gewählte Editor eine Drehen-Funktion bietet, verwenden Sie die kleinste Korrektur, die die Szene aufrecht stellt. Arbeiten Sie mit einer Kopie oder einem nicht-destruktiven Projekt. Kombinieren Sie beim ersten Test nicht Drehung, neuen Zuschnitt, Geschwindigkeitsänderung und Qualitätsänderung: Mehrere gleichzeitige Änderungen machen das Ergebnis schwerer zu beurteilen. Dies ist ein allgemeiner Bearbeitungsablauf, keine Aussage darüber, dass CruxCut eine manuelle Drehfunktion enthält.

Speichern Sie einen kurzen Test mit erkennbaren Merkmalen am Anfang, in der Mitte und am Ende. Öffnen Sie die gespeicherte Datei außerhalb des Editors. Wenn sie sowohl in der Galerie als auch dort aufrecht ist, wo das Original falsch angezeigt wurde, haben Sie eine brauchbare korrigierte Quelle für die nächste Bearbeitung. Wenn die gespeicherte Kopie immer noch seitlich gedreht ist, hören Sie auf, bei aufeinanderfolgenden Exporten weitere Drehungen zu stapeln. Gehen Sie zum Original zurück und prüfen Sie die aktuelle Hilfe oder den Support des Editors zu unterstützten Dateitypen und zum Umgang mit der Ausrichtung.

Dann das endgültige Format wählen

Sobald die Ausrichtung konsistent ist, entscheiden Sie, ob Sie eine Querformat-Kopie zur Analyse oder eine Hochformat-Kopie zum Teilen brauchen. Prüfen Sie den ganzen Versuch, bevor Sie den Zuschnitt enger machen. Lassen Sie genug Platz für weite Züge, Fußplatzierungen und das Top; ein korrigiertes erstes Bild beweist nicht, dass die ganze Sequenz hineinpasst. Behalten Sie beim Trimmen die nützliche Vorbereitung und das Ergebnis. Eine geteilte Kopie immer wieder zu exportieren ist kein Ersatz dafür, das Original aufzubewahren.

Beispiel: aufrecht in der Galerie, seitlich im Editor

Angenommen, ein Schild an der Wand ist in der Galerie waagerecht, nach dem Import aber senkrecht. Vergleichen Sie das unveränderte Original in einem anderen verfügbaren Player. Wenn der Unterschied auf einen Importweg beschränkt ist, notieren Sie diesen Weg und testen Sie eine einzige korrigierte Kopie in einem Editor, der Drehen unterstützt. Prüfen Sie das Ergebnis außerhalb dieses Editors, bevor Sie weitermachen. Dies ist ein Diagnosebeispiel, kein beobachteter CruxCut-Vorfall. Ein Screenshot allein kann nicht zeigen, wie das fertige Video abgespielt wird.

Die Datei prüfen, die Sie tatsächlich senden

  • Bewahren Sie das Original auf und finden Sie die Datei, die zuerst seitlich gedreht aussieht.
  • Vergewissern Sie sich, dass eine Drehung nötig ist und nicht ein Zuschnitt oder eine Änderung des Bildschirmlayouts.
  • Korrigieren Sie einmal und prüfen Sie dann die gespeicherte Kopie außerhalb des Editors.
  • Sehen Sie sich Anfang, Mitte und Ende vor dem Teilen an.
  • Verwenden Sie nur Material, das Sie teilen dürfen, auch in Bezug auf erkennbare Personen.

Wenn das Problem bestehen bleibt, geben Sie dem Support das Aufnahmegerät an, die App, die das Video richtig anzeigt, die App, die es falsch anzeigt, und ob auch ein gespeicherter Test fehlschlägt. Bieten Sie über den vorgesehenen Supportkanal ein kurzes Beispiel an, das Sie weitergeben dürfen – ohne Zugangsdaten oder private Aufnahmen von Unbeteiligten. Beschriften Sie korrigierte Kopien eindeutig mit dem Ablauf zum Organisieren. Bei einem separaten Detailverlust siehe Fehlerbehebung zur Qualität beim Teilen.
