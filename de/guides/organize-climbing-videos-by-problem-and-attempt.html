Klettervideos organisieren

Klettervideos nach Boulder und Versuch organisieren

Finden Sie in der nächsten Session den richtigen Versuch – mit einem einfachen Benennungssystem, einer kurzen Session-Notiz und einer klaren Trennung zwischen Originalaufnahmen und bearbeiteten Clips.

Veröffentlicht am 31. Oktober 2026 · Vom CruxCut-Team

Ein kleines Verzeichnis statt eines komplizierten Archivs

Nach einer Klettersession können in der Mediathek Aufwärm-Clips, mehrere Versuche an einem Boulder und Clips von verschiedenen Wänden liegen. Die nützliche Frage ist einfach: Finden Sie einen bestimmten Versuch in der nächsten Session, ohne jede Aufnahme anzusehen?

Eine Notiz auf dem Handy und ein Album pro Session reichen für den Anfang. Dieser Ablauf erfordert keine bestimmte Bearbeitungs-App, keine automatische Routenerkennung und keinen kostenpflichtigen Speicherdienst. Nutzen Sie die Werkzeuge, die Sie schon haben, und halten Sie das System so klein, dass Sie es aktualisieren können, solange Sie sich noch an die Session erinnern.

Jeder Session ein Datum und einen Ort geben

Legen Sie ein Album oder einen Ordner mit einem sortierbaren Datum und einer kurzen Ortsbezeichnung an, etwa 2026-10-31 Halle-West. Verwenden Sie das tatsächliche Datum der Session, nicht das Datum, an dem Sie das Video später bearbeiten oder hochladen. Wenn Sie an einem Tag zwei Orte besuchen, geben Sie ihnen unterschiedliche Bezeichnungen.

Alben in Fotomediatheken fassen oft vorhandene Objekte zusammen, statt unabhängige Kopien zu erstellen. Prüfen Sie, wie Ihre eigene Mediathek funktioniert, bevor Sie ein Album als Backup betrachten oder die Originalaufnahme löschen. Eine Datei in einem Dateimanager zu verschieben oder zu entfernen kann sich anders verhalten, als ein Objekt aus einem Album zu entfernen.

Eine Boulder-Bezeichnung verwenden, die auch später noch Sinn ergibt

Eine Griff-Farbe allein kann mehrdeutig sein, wenn mehrere Boulder dieselbe Farbe haben. Schreiben Sie eine kurze Bezeichnung aus Wandbereich und einem erkennbaren Merkmal, zum Beispiel West-Höhle blau Volumen-Start. Fügen Sie den Grad nur hinzu, wenn Sie möchten; ein Grad ist keine eindeutige Kennung.

Verwenden Sie bei Routen und Bouldern draußen den etablierten Namen, wenn er bekannt ist. Veröffentlichen Sie keine sensiblen Orte oder Zustiegsdetails. In der Halle ändern sich Boulder nach dem Umschrauben, deshalb behalten Sie das Session-Datum bei, statt anzunehmen, dass eine Bezeichnung immer denselben Boulder meint.

Ein Referenzfoto kann helfen, wenn die Halle Fotografieren erlaubt. Fotografieren Sie die Griffe, die Sie brauchen, vermeiden Sie unnötige Aufnahmen von Personen und betreten Sie keine Landezone, um ein besseres Katalogbild zu bekommen.

Versuche in Aufnahmereihenfolge nummerieren

Verwenden Sie innerhalb jedes Boulders A01, A02 und A03 in der Reihenfolge der Aufnahme. Das sind Aufnahmebezeichnungen, nicht unbedingt eine Zählung aller Versuche: Manche Versuche wurden vielleicht nicht gefilmt. Vermerken Sie diesen Unterschied, wenn er für Ihr Trainingslog wichtig ist.

Wenn Ihre Foto-App das Umbenennen des Originalvideos nicht erlaubt, exportieren Sie keine neue Kopie, nur um einen Dateinamen zu erzeugen. Schreiben Sie die Bezeichnung in eine Bildunterschrift, falls unterstützt, oder verwenden Sie eine Notiz, die auf die in Ihrer Mediathek angezeigte Aufnahmezeit verweist. Prüfen Sie, ob der Zeitstempel den richtigen Clip bezeichnet, bevor Sie sich darauf verlassen.

Beispiel für eine Session-Notiz

  • Session: 2026-10-31, Halle-West
  • Boulder: West-Höhle blau Volumen-Start
  • A01: Aufnahme beginnt 18:42; erster gefilmter Versuch
  • A02: Aufnahme beginnt 18:47; andere Abfolge mit dem rechten Fuß
  • A03: Aufnahme beginnt 18:53; vollständig gefilmter Versuch

Dies ist ein veranschaulichendes Benennungsbeispiel, kein echtes Nutzerergebnis und kein von CruxCut erstelltes Log.

Trennen, was die Datei ist und was passiert ist

Notieren Sie das Ergebnis nur kurz, wenn es nützlich ist: vollständiger Versuch, Sturz vor dem letzten Zug oder Kamera hat den Start verpasst. Machen Sie den Dateinamen nicht zu einer langen Kritik. Halten Sie eine Bewegungsfrage in der Notiz fest, statt einem Sturz selbstsicher eine Ursache zuzuschreiben.

Zum Beispiel ist „A02: linker Fuß nicht sichtbar“ nützlicher als die Vermutung, der Fuß sei abgerutscht. Um sichtbare Bewegungen zu vergleichen, nachdem Sie die Dateien gefunden haben, folgen Sie unserer Anleitung zur Beta-Analyse von Klettervideos. Eine organisierte Mediathek hilft Ihnen, Belege wiederzufinden; sie macht den Kamerawinkel nicht aussagekräftiger.

Originale, Analyse-Clips und Schnitte zum Teilen auseinanderhalten

Die vollständige Originalaufnahme, ein kürzerer Analyse-Clip und ein vertikaler Social-Media-Schnitt dienen unterschiedlichen Zwecken. Geben Sie abgeleiteten Versionen klare Bezeichnungen wie A02-analyse oder A02-social-v1. Wenn Sie eine weitere Version exportieren, erhöhen Sie die Versionsnummer, statt sie mit einem neuen Kletterversuch zu verwechseln.

Behalten Sie einen Verweis auf das Original. Ein Social-Media-Zuschnitt kann die Füße, umliegende Griffe oder die Vorbereitung vor der Crux entfernen. Ein nützlicher Analyse-Clip kann bewusst länger sein. Für den Bearbeitungsschritt siehe den Ablauf für Kletter-Highlights; für die Kameraposition in der nächsten Session siehe Grundlagen zum Filmen und Schneiden.

Dieses Benennungssystem ist ein manueller Ablauf für Ihre Mediathek. Es wird nicht behauptet, dass CruxCut Ihre Versuche automatisch benennt, katalogisiert, sichert oder synchronisiert.

Löschen ist eine eigene Entscheidung

Löschen Sie eine Quelle nicht nur deshalb, weil ein exportierter Clip in der Mediathek erscheint. Öffnen Sie zuerst den Export und prüfen Sie Anfang, Ende, Bild und den Ton, den Sie behalten wollten. Vergewissern Sie sich, dass die Datei dort verfügbar ist, wo Sie sie erwarten, statt sich nur auf ein Vorschaubild zu verlassen.

Wenn Sie ein Backup brauchen, prüfen Sie eine unabhängige Kopie über den Speicherweg Ihrer Wahl. Eine per Cloud synchronisierte Mediathek ist nicht automatisch ein separates Backup: Prüfen Sie, wie der Dienst mit Löschen und Wiederherstellen umgeht. Behalten Sie die Originale, die Sie später für einen neuen Bildausschnitt oder eine Beta-Analyse brauchen könnten; löschen Sie versehentliche oder unerwünschte Aufnahmen erst, nachdem Sie sie angesehen haben.

Zum Schluss ein Zwei-Minuten-Test zum Wiederfinden

  1. Öffnen Sie die Session-Notiz und wählen Sie einen Boulder.
  2. Finden Sie A02, ohne andere Videos abzuspielen.
  3. Finden Sie das zugehörige Original und unterscheiden Sie es vom Social-Media-Schnitt.
  4. Prüfen Sie, ob die Frage für die nächste Session noch verständlich ist.

Wenn das zu viel Suchen erfordert, vereinfachen Sie die Bezeichnungen oder ergänzen Sie das fehlende Wanddetail. Sie brauchen kein perfektes Archiv. Sie brauchen einen zuverlässigen Weg, den nächsten Clip zu finden, der eine Analyse wert ist.

Bevor Sie den Versuch einer anderen Person teilen, fragen Sie um Erlaubnis und prüfen Sie den Hintergrund auf Personen, die nicht zu sehen sein sollten. Halten Sie private Notizen und persönliche Details aus öffentlichen Dateinamen und Bildunterschriften heraus.
