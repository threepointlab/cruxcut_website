클라이밍 영상 정리

클라이밍 영상을 문제별·시도별로 정리하는 법

간단한 이름 규칙, 짧은 세션 메모, 원본과 편집 클립의 분명한 구분만 있으면 다음 세션에서 원하는 시도를 바로 찾을 수 있습니다.

2026년 10월 31일 게시 · CruxCut 팀

복잡한 아카이브 말고 작은 색인을 만드세요

클라이밍 세션이 끝나면 카메라 롤에는 워밍업, 한 문제에 대한 여러 번의 시도, 여러 벽에서 찍은 클립이 섞여 있기 마련입니다. 중요한 질문은 간단합니다. 다음 세션에서 모든 영상을 다 보지 않고도 특정 시도를 찾을 수 있나요?

휴대폰 메모 하나와 세션 앨범 하나면 시작하기에 충분합니다. 이 방법에는 특정 편집 앱, 루트 자동 인식, 유료 저장 서비스가 필요 없습니다. 이미 가진 도구를 쓰고, 세션 기억이 생생할 때 바로 업데이트할 수 있을 만큼 체계를 작게 유지하세요.

세션마다 날짜와 장소를 붙이세요

정렬하기 쉬운 날짜와 짧은 장소 이름으로 앨범이나 폴더를 하나 만드세요. 예를 들면 2026-10-31 웨스트암장처럼요. 나중에 편집하거나 업로드한 날짜가 아니라 실제 세션 날짜를 쓰세요. 하루에 두 곳을 갔다면 이름을 서로 다르게 붙이세요.

사진 보관함의 앨범은 독립적인 사본을 만드는 것이 아니라 기존 항목을 묶어 보여 주는 것일 수 있습니다. 앨범을 백업으로 여기거나 원본 영상을 지우기 전에 내 보관함이 어떻게 동작하는지 확인하세요. 파일 관리 앱에서 파일을 옮기거나 지우는 것은 앨범에서 항목을 빼는 것과 다르게 동작할 수 있습니다.

나중에 봐도 알아볼 수 있는 문제 이름을 쓰세요

같은 색 홀드를 쓰는 문제가 여러 개 있으면 홀드 색만으로는 헷갈릴 수 있습니다. 벽 구역과 알아보기 쉬운 특징을 넣어 짧게 이름을 붙이세요. 예를 들면 웨스트동굴-파랑-볼륨스타트처럼요. 난이도는 원할 때만 덧붙이세요. 난이도만으로는 문제를 구분할 수 없습니다.

자연 암장의 루트라면 이미 알려진 루트나 문제 이름을 쓰세요. 민감한 위치나 접근 정보는 공개하지 마세요. 실내 암장은 세팅이 바뀌면 문제도 바뀌니, 같은 이름이 늘 같은 문제를 가리킨다고 생각하지 말고 세션 날짜를 함께 남기세요.

암장에서 사진 촬영을 허용한다면 참고용 사진이 도움이 됩니다. 필요한 홀드만 담고, 불필요하게 사람을 찍지 말고, 더 좋은 기록 사진을 얻겠다고 착지 구역에 들어가지 마세요.

시도는 녹화한 순서대로 번호를 매기세요

문제마다 녹화한 순서대로 A01, A02, A03을 붙이세요. 이것은 녹화 번호일 뿐, 실제로 시도한 횟수와 꼭 같지는 않습니다. 찍지 않은 시도도 있을 수 있으니까요. 훈련 일지에 중요하다면 이 차이를 적어 두세요.

사진 앱에서 원본 영상의 이름을 바꿀 수 없다면, 파일 이름을 붙이려고 새 사본을 내보내지 마세요. 지원된다면 캡션에 이름을 적고, 아니면 보관함에 표시되는 녹화 시각을 가리키는 메모를 쓰세요. 그 시각에 기대기 전에 맞는 클립을 가리키는지 확인하세요.

세션 메모 예시

  • 세션: 2026-10-31, 웨스트암장
  • 문제: 웨스트동굴-파랑-볼륨스타트
  • A01: 18:42 녹화 시작, 처음 찍은 시도
  • A02: 18:47 녹화 시작, 오른발 순서를 다르게
  • A03: 18:53 녹화 시작, 끝까지 찍힌 시도

이것은 이름 붙이기를 설명하기 위한 예시이며, 실제 사용자 결과나 CruxCut이 만든 기록이 아닙니다.

파일의 종류와 일어난 일을 구분하세요

결과 메모는 쓸모 있을 때만 짧게 남기세요. 끝까지 등반, 마지막 무브 전 추락, 카메라가 시작을 놓침 같은 식으로요. 파일 이름을 긴 평가로 만들지 마세요. 추락의 원인을 단정하기보다 동작에 대한 질문을 메모에 남기세요.

예를 들어 "A02: 왼발 안 보임"이 발이 미끄러졌다고 추측하는 것보다 더 쓸모 있습니다. 파일을 찾은 뒤 눈에 보이는 동작을 비교하려면 클라이밍 영상 베타 리뷰 가이드를 따라 해 보세요. 보관함을 정리하면 근거를 찾기는 쉬워지지만, 카메라 각도가 보여 주는 정보가 늘어나지는 않습니다.

원본, 리뷰 클립, 공유용 편집본을 구분하세요

전체 원본 영상, 짧은 리뷰 클립, 세로 SNS 편집본은 쓰임이 다릅니다. 파생본에는 A02-리뷰나 A02-SNS-v1처럼 분명한 이름을 붙이세요. 다른 버전을 내보낸다면 새로운 클라이밍 시도와 헷갈리지 않게 버전 번호를 올리세요.

원본을 찾아갈 수 있는 단서를 남겨 두세요. SNS용 크롭은 발, 주변 홀드, 크럭스 전 준비 동작을 잘라 낼 수 있습니다. 쓸모 있는 리뷰 클립은 일부러 더 길게 둘 수도 있습니다. 편집 단계는 클라이밍 하이라이트 만들기를, 다음 세션의 카메라 위치는 촬영과 편집 기본기를 참고하세요.

이 이름 규칙은 직접 하는 보관함 정리 방법입니다. CruxCut이 시도에 자동으로 이름을 붙이거나, 분류하거나, 백업하거나, 동기화한다고 주장하지 않습니다.

삭제는 따로 결정하세요

내보낸 클립이 보관함에 보인다고 원본을 지우지 마세요. 먼저 내보낸 파일을 열어 시작, 끝, 화면, 남기려던 소리를 확인하세요. 썸네일만 믿지 말고, 파일이 예상한 위치에 있는지 확인하세요.

백업이 필요하다면 선택한 저장 방식으로 독립적인 사본이 있는지 확인하세요. 클라우드와 동기화된 보관함이 자동으로 별도 백업이 되는 것은 아닙니다. 서비스의 삭제와 복구 방식을 확인하세요. 나중에 구도를 다시 잡거나 베타 리뷰에 쓸 수 있는 원본은 보관하고, 실수로 찍었거나 필요 없는 영상은 확인한 뒤에만 지우세요.

마지막으로 2분 찾기 테스트를 해 보세요

  1. 세션 메모를 열고 문제 하나를 고르세요.
  2. 관련 없는 영상을 재생하지 않고 A02를 찾아보세요.
  3. A02의 원본을 찾아 SNS 편집본과 구분해 보세요.
  4. 다음 세션에 확인할 질문이 여전히 이해되는지 확인하세요.

찾는 데 너무 오래 걸린다면 이름을 단순하게 바꾸거나 빠진 벽 정보를 추가하세요. 완벽한 아카이브는 필요 없습니다. 다음에 리뷰할 클립을 확실하게 찾는 방법이 있으면 됩니다.

다른 사람의 시도를 공유하기 전에는 허락을 받고, 배경에 담기면 안 되는 사람이 없는지 확인하세요. 공개되는 파일 이름이나 캡션에는 개인적인 메모나 개인 정보를 넣지 마세요.
